# Starter corpus

`starter_corpus.jsonl` contains short, source-linked evidence cards, not copies of
the underlying documents. Each line is a retrieval chunk with lifecycle metadata.
The cards summarize public material and are intended to make the demo runnable.

Before using the navigator for real regulatory work:

1. Download and review current official FDA, EUR-Lex, and IMDRF documents.
2. Add organization-authorized copies through `regnav ingest`.
3. Supply licensed IEC/ISO content only where your license permits it.
4. Review every source date, status, and supersession flag.

IEC and ISO standards are copyrighted. This repository deliberately stores only
catalog-level scope/classification summaries and links; it does not reproduce clauses.
